## Data Dictionary

The data dictionary Excel workbook is stored PGP-encrypted to protect draft content. To decrypt:

```sh
gpg --decrypt \
  "DRAFT Working Copy CDG Consensus - PeRef Logical Information Model (Data Dictionary).xlsx.gpg" \
  > "DRAFT Working Copy CDG Consensus - PeRef Logical Information Model (Data Dictionary).xlsx"
```

You must have the repository maintainer's PGP public key in your keyring (or be the key owner) to decrypt.
